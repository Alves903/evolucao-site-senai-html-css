## 📌 Sobre o Projeto

Este projeto foi desenvolvido como atividade prática do SENAI com o objetivo de evoluir um site básico, tornando-o mais completo, organizado e visualmente agradável utilizando apenas HTML e CSS.

## 🚀 Funcionalidades

* 📄 Estrutura completa em HTML
* 🎨 Estilização com CSS
* 🔗 Navegação interna entre seções
* 🖼️ Inserção de imagens com atributos alt e title
* 📊 Tabelas organizadas com thead, tbody e tfoot
* 📋 Listas ordenadas e não ordenadas
* 📩 Formulário de contato
* 🌐 Links externos com target="_blank"
* 📑 Página extra "Sobre"

## 📂 Estrutura do Projeto

```
📁 evolucao-site-senai-html-css
 ├── index.html
 ├── sobre.html
 └── style.css
```

## 🎯 Objetivo

Aplicar conceitos básicos de desenvolvimento web, demonstrando domínio de:

* HTML semântico
* CSS básico
* Organização de conteúdo
* Estruturação de páginas

## ⚠️ Regras do Projeto

* ❌ Sem JavaScript
* ❌ Sem Flexbox ou Grid
* ✅ Apenas HTML e CSS básico

## 💻 Como visualizar

1. Baixe ou clone o repositório
2. Abra o arquivo index.html no navegador
